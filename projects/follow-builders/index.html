FOLLOW
BUILDERS

一个 AI 行业资讯自动推送系统：自动浏览、信息筛选、摘要提炼、网页展示与邮件定时推送。

2026.05 — 至今 AI NEWS / AUTOMATION 产品设计 + AI 工具开发 + 部署落地
Claude CodeCursorRenderFlaskLLM
01 — OVERVIEW

THE
OVERVIEW

Follow Builders 是一个面向 AI 从业者的每日资讯日报。它自动浏览 X / Twitter 的 Builder 圈层，筛掉噪声，用 LLM 提炼真正重要的内容，渲染成可读的页面，并按固定时间自动推送。

整条链路是：Information → Processing → Generation → Distribution。

02 — PROBLEM

THE
PROBLEM

全球 AI 从业者资讯碎片化、有效信噪比低，缺少稳定的信息入口。

要么整天刷信息流，要么错过重要动态 —— 两者都不算一个「系统」。

03 — THINKING

THE
THINKING

我独立定义了产品形态：每日定时聚合 X / Twitter Builder 圈层动态，输出「原文要点 + AI 解读 + 一句话结论」的固定结构。

把输出结构固定下来，是日报能被长期使用的关键：读者知道该看哪里，摘要模型也有明确的填空目标。

04 — PROCESS

THE
PROCESS

采集
按计划浏览 Builder 圈层动态。
去重
跨来源识别并剔除重复内容。
筛选
关键词过滤，压低噪声。
摘要
LLM 把每条内容压缩为要点 + 一句话结论。
排版
渲染为可读的日报页面。
推送
Cron 定时调度 + 飞书自定义机器人 Webhook 推送。
05 — SOLUTION

THE
SOLUTION

基于开源采集框架二次开发，搭建采集 → 去重 → 关键词过滤 → LLM 摘要 → 排版渲染 → 推送的全链路工作流；Render 部署 + Cron 定时调度 + 飞书自定义机器人 Webhook。

  • 为 AI 资讯提供一个稳定的每日入口。
  • 固定输出结构：原文要点 + AI 解读 + 一句话结论。
  • 无人值守运行，无需人工编辑。
06 — RESULT

THE
RESULT

收集使用者反馈迭代 3 个版本，优化排版可读性、关键词噪声过滤与更新时效；日报生产由人工变为全自动输出，效率提升约 90%。

  • 3版本迭代
  • 90%效率提升
  • 6全链路环节
  • 0人工介入

08 — REFLECTION

WHAT I
LEARNED

自动日报最难的部分不是写代码，而是定义「什么算有效信息」。先把输出结构定下来之后，后面每个决定都变简单了：保留哪些信源、过滤哪些关键词、摘要该多长。

连续公开迭代三个版本也让我确认：小而诚实的迭代循环，比一次性大版本更有效。
