艺人跨平台内容数据统计工具

2026.05 PRODUCT / DATA 产品设计 + MVP 开发
01 — 问题

PROBLEM

需求来自微博实习的真实痛点：人工统计艺人各平台发布数据，单次耗时约 20 分钟、易遗漏，且难以横向对比竞品。

02 — 为什么

THINKING

把重复劳动交给工具，输入只需要「艺人主页 + 时间范围」。

03 — 怎么做

ACTION

使用 Claude Code 完成 MVP：输入艺人主页与时间范围，自动汇总多平台发布条数并输出竞品对比。

04 — 结果

RESULT

热门平台发布条数与人工复核结果一致，覆盖 3 个平台，单次统计耗时从约 20 分钟降至 5 秒。
