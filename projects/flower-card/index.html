母亲节祝福花卡片网站：输入姓名，一键生成专属花卡并在线使用。

2026 AI / INTERACTION 想法 + 交互设计 + 前端实现
01 — 问题

PROBLEM

母亲节祝福的门槛不是心意，而是制作：不知道该写什么，也不值得为一张贺卡去打开设计软件。

02 — 为什么

THINKING

把交互压缩到一个输入：一个名字进去、一张卡片出来，并且移动端优先 —— 因为它就是在手机上发出去的。

03 — 怎么做

ACTION

使用 Claude Code 完成单页网站：输入名字后生成花卡，构图、字体与版式围绕这个名字排布，并可切换样式直到感觉对了。

04 — 结果

RESULT

已上线可用：把「想送祝福但不会做图」变成大约 30 秒输入一个名字。
