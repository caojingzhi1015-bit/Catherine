01 — OVERVIEW

THE
OVERVIEW

围绕母亲节用户的情感祝福需求打造的轻量互动网站：输入姓名一键生成专属花卡，并支持在线使用。

02 — PROBLEM

THE
PROBLEM

母亲节祝福的门槛从来不是心意，而是「制作」。不知道该写什么，也不值得为一张贺卡去打开设计软件。

  • 有心意，但没时间做设计。
  • 想要专属感，而不是通用表情包。
  • 必须几秒内可用 —— 在手机上、在聊天窗口里。
03 — THINKING

THE
THINKING

把交互压缩到一个输入：一个名字进去，一张卡片出来，其余全部自动生成。

重点不是「从列表里挑一个」，而是「这一张是给你做的」。所以生成的字、版式和切换的样式需要一起变化。

04 — PROCESS

THE
PROCESS

场景
先把要服务的真实场景写下来。
情感
明确卡片要让发送者感到「我能做到」，而不是笨拙。
思路
把流程压缩到一个输入框。
交互
设计「输入 → 生成 → 预览 → 使用」的闭环。
切换
加入样式切换，同一个名字能得到不同气质的卡片。
迭代
删掉一切让它像「表单」的步骤。
05 — SOLUTION

THE
SOLUTION

一个单页网站：输入名字后生成花卡，构图、字体与版式围绕这个名字排布，并且可以切换样式直到感觉对了。

  • 零学习成本：一个输入，一个输出。
  • 移动端优先，因为它就是在手机上发出去的。
  • 用样式切换实现个性化，而不是做一堆设置项。
06 — RESULT

THE
RESULT

已上线可用。把「想送祝福但不会做图」变成大约 30 秒输入一个名字就完成。

  • 1输入项
  • 30s生成一张卡片
  • 0设计门槛
  • 100%移动端可用
