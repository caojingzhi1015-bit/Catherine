AI 行业资讯自动推送系统

产品设计 + AI 工具开发 + 部署落地

问题
全球 AI 从业者资讯碎片化、有效信噪比低，缺少稳定的信息入口。
为什么
独立定义产品形态：每日定时聚合 X/Twitter Builder 圈层动态，输出「原文要点 + AI 解读 + 一句话结论」的固定结构。
怎么做
基于开源采集框架二次开发，搭建采集 → 去重 → 关键词过滤 → LLM 摘要 → 排版渲染 → 推送全链路工作流；Render 部署 + Cron 定时调度 + 飞书自定义机器人 Webhook。
结果
收集使用者反馈迭代 3 个版本，优化排版可读性、关键词噪声过滤与更新时效；日报生产由人工变为全自动输出，效率提升约 90%。

2026.10

OPEN
SOURCE

AI Agent 工具链开源

工具链设计 + 开源

问题
内容生产中有大量重复劳动：海报 Prompt 反复试错、视频脚本靠人工扒。
为什么
把个人工作流固化成可复用的规则与 pipeline，开源给有同样需求的使用者。
怎么做 · 结果
halftone-pop — 半调拼贴海报 Prompt 生成器：把「参考图 → 主色提取 → 对比度量化 → 双路线 Prompt → 成图」固化为可复用规则，配套 OpenCV 图像处理脚本；MIT 开源。
video-script-extractor — 视频脚本提取 pipeline：yt-dlp 下载 → ffmpeg 抽音 → faster-whisper 语音转写与 OCR 硬字幕识别双路并行、按时间轴对齐 → LLM 结构化分段 → 输出双语 SRT 与 Markdown 报告；已用于 B 站 / 抖音多语种视频脚本提取（韩综、男团物料等），单次「视频 → 成稿」耗时由 3 小时降至 20 分钟。
